# 🧭 モード選択ガイド

| 条件 | 選択 |
|---|---|
| とにかく簡単に始めたい | `01-local-pc-always` |
| PCを使う時間だけ電源を入れたい | `02-local-pc-scheduled` |
| Piは常時、重いVOICEVOXはPCへ | `03-pi-bot-pc-voicevox` |
| 外出先からも安定運用したい | `04-vps` |

## 🏠 最初のおすすめ

すでにPCがあるなら `01-local-pc-always` が最短です。

PCの消費電力が気になるなら `02-local-pc-scheduled`。

24時間起動の低消費電力機器があるなら `03-pi-bot-pc-voicevox` が使いやすい構成です。

自宅ネットワークやPCの稼働に依存したくなったら `04-vps` へ移行します。
