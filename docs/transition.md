# 🔀 構成の移行ルート

v5 は、最初から最も複雑な構成にしないことを重視します。

```text
🏠 自宅PC 1台
      │
      ├─ メモリ不足なし → そのまま
      │
      └─ メモリ不足
           ↓
🍓 Pi = Bot / 🖥️ PC = VOICEVOX
      │
      └─ 外へ出したい
           ↓
☁️ VPS 1GB × 1
      │
      └─ 分離が必要
           ↓
☁️ 512MB Bot + 1GB VOICEVOX
```

TTSキャッシュとWAVのディスク化は、どの段階でも共通です。
